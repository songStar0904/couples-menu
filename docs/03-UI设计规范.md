# 「情侣菜单」UI 设计规范

> 版本 v1.0 · 2026-10-29
> 设计基调：**圆润、柔和、手作感**。像一本两个人的手账，而不是一个交易工具。

## 1. 设计原则

1. **温度感优先**：柔和渐变、大圆角、emoji 插画体系，杜绝冷硬的后台感；
2. **零图片资产**：图标全部使用 emoji + CSS 绘制，插画用 emoji 组合，保证加载速度与可维护性；
3. **一套变量**：所有颜色/圆角/间距由 `--cm-*` CSS 变量驱动，双主题（暖粉/雾蓝）一键切换；
4. **反馈及时**：每个动作都有 loading / 成功反馈 / 触感震动（下单、签到）。

## 3. 字体阶梯（rpx）

| 级别 | 字号 | 字重 | 用途 |
|---|---|---|---|
| display | 64 | 600 | 余额数字 / 在一起天数 |
| title | 40 | 600 | 卡片大标题 |
| h2 | 34 | 600 | 区块标题 |
| body | 30 | 400 | 正文 |
| sub | 26 | 400 | 次要说明 |
| caption | 22 | 400 | 标签/时间 |

## 4. 几何与间距

- 圆角：卡片 `28rpx`；按钮/输入框 `24rpx`；胶囊 `999rpx`；
- 间距基准：页面左右边距 `32rpx`；卡片内边距 `28rpx`；区块间距 `24rpx`；
- 卡片阴影：`0 6rpx 24rpx rgba(60,40,60,.06)`（`--cm-shadow`）；
- 页面底部：`.safe-bottom`（`env(safe-area-inset-bottom)` + 24rpx）。

## 5. 组件规范（components/ui）

| 组件 | 关键 props / 用法 |
|---|---|
| `ui-button` | type: primary/soft/danger/ghost；size: lg/md/sm；loading/disabled；`bind:tap` |
| `ui-cell` | icon(emoji)/title/label/arrow/slot right；`bind:tap` |
| `ui-card` | title/subtitle + slot；统一直角阴影 |
| `ui-dialog` | `selectComponent('#dialog').confirm({title,content})` 返回 Promise |
| `ui-empty` | emoji/text/sub + slot button |
| `ui-skeleton` | type: list/detail/cards；loading 时占位 |
| `ui-tag` | type: primary/soft/success/warning/danger/line；size: md/sm |
| `ui-badge` | count（>99 显示 99+）/ dot |
| `ui-price` | value；❤ + 数字，主题色 |
| `ui-stepper` | value/min/max/step；`bind:change` |
| `ui-segmented` | options/value；`bind:change`；滑块动画 |

业务组件（components/business）：`dish-card`（菜品横向卡片，图片或分类 emoji）、`order-card`（订单列表卡，状态色标签+操作按钮 slot）、`dynamics-item`（动态时间线条目）、`template-card`（渐变+emoji 封面）、`sign-calendar`（月历签到格）、`points-badge`（心意值胶囊）。

## 7. 页面结构约定

```
<view class="page {{themeClass}}">
  [骨架屏 ui-skeleton wx:if="{{loading}}"]
  [内容]
  [ui-dialog id="dialog"] [ui-toast 区域用 wx.showToast]
  <view class="safe-bottom"/>   ← 可滚动页底部
</view>
```

- 每页 onShow：`require('utils/theme').apply(this)` 同步主题类名 + tabBar 选中项；
- 列表页统一「下拉刷新 + 触底分页」；分页游标用最后一条 createdAt。

## 8. 交互动效

- 卡片按压：`hover-class="press"`（scale 0.98 + 透明度）；
- Segmented 滑块：transition 240ms ease；
- 签到/下单成功：`wx.vibrateShort({type:'medium'})` + toast；
- 点单按钮：`bindtap` 前置 200ms 防抖。

## 9. 文案语气

用「TA / 你 / 我们」而非「该用户」；错误提示不出现技术词；空状态给行动出口（如"去发现页找灵感 →"）。示例：
- 心意值不足：「心意值不够啦，去签到赚一点 ❤」
- 主厨休息：「TA 今天休息 😴 菜单暂不接单」
- 绑定成功：「💞 绑定成功！你们各获得 66 心意值」
