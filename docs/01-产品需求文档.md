# 「情侣菜单」产品需求文档（PRD）

> 版本 v1.0 · 2026-10-29
> 一句话定位：为情侣打造的专属点餐小程序——TA 是你的私厨，你是 TA 的常客。

## 1. 产品定位

恋爱关系中的两人互为「主厨 🧑‍🍳」和「食客 🍽️」。主厨发布自己的专属菜单（真实拿手菜 + 心意服务，如"一个拥抱""陪你看一场电影"），食客用**心意值**下单点菜，主厨接单、完成履约，形成「点餐 → 接单 → 完成 → 感谢」的仪式感闭环。

核心价值：
- **仪式感**：把"今天吃什么/做什么"变成一场小小的点餐游戏；
- **双向流动**：心意值在两人之间转移，付出被看见、被"付费"；
- **私有专属**：仅限绑定的两个人使用，体验版即可长期使用，无需发布上线。

## 2. 用户与角色

| 角色 | 说明 |
|---|---|
| 主厨（被点方） | 维护自己的菜单，处理订单：接单 → 完成 |
| 食客（点单方） | 浏览伴侣菜单，用心意值下单 |
| 双重角色 | 两人**互相**都可以点对方的单、维护自己的菜单，角色随页面视角切换 |

## 3. 核心玩法闭环

```
绑定伴侣 → 主厨上架菜品/心意服务 → 食客下单（扣心意值）→ 主厨接单
        → 主厨完成（收到心意值）→ 食客评价感谢 → 心意值可通过签到/互动补充
```

## 4. 情侣绑定规则

- 一方在「绑定」页生成 **6 位邀请口令**（有效期 10 分钟，可重新生成）；
- 另一方输入口令完成绑定，也可复制口令微信发给对方；
- 每个账号同一时间**只能绑定一位伴侣**；
- 绑定成功：双方各奖励 66 心意值，自动记录纪念日（可在设置中修改）；
- 解绑：二次确认后立即生效，双方菜单/订单/账本数据保留但不再互相可见。

## 5. 心意值经济体系

> 虚拟积分替代真实支付，无需商户资质。后续如开通企业主体可在 API 层无缝接入微信支付。

| 途径 | 数值 | 说明 |
|---|---|---|
| 新用户注册 | +200 | 一次性 |
| 绑定伴侣 | +66 | 一次性，双方各得 |
| 每日签到 | +5 | 每天一次 |
| 连续签到满 7 天 | 额外 +10 | 每 7 天一个循环 |
| 完成订单（主厨） | + 菜品定价 | 食客支付的心意值全额转移给主厨 |

消耗：下单时按主厨定价扣除（0 心意值 = 免费的心意服务也允许）。

## 6. 五大模块功能清单

### 6.1 首页
- 顶部问候 + 头像 + 心意值胶囊（点击进入心意值页）
- 「在一起 N 天」情侣卡：双头像、纪念日（未设置时引导设置）、未签到时的签到按钮
- 待办提醒条：有待接单（主厨视角）时提示 "有 N 个新订单待接单"
- 今日推荐：伴侣菜单中随机 2 个菜品，点击直达下单确认页
- 我们的动态：双方点单/接单/完成/评价/绑定的时间线（最近 5 条）
- 快捷入口：我的菜单 / 心意值 / 模板灵感 / 设置

### 6.2 菜单（双视角，顶部 Segmented 切换）
- **去点单（伴侣菜单）**：左侧分类导航 + 右侧菜品列表；菜品卡（图/名称/描述/定价）+「点单」按钮；主厨开启「今日休息」时显示休息横幅并禁点
- **我的菜单（管理）**：
  - 顶部：累计被点统计、「今日休息」开关、新建菜品按钮、分类管理入口
  - 菜品列表（按分类分组）：上下架切换、点击进入编辑
- **空状态**：未绑定伴侣 → 引导绑定；伴侣菜单为空 → 引导去发现页导入模板

### 6.3 发现
- 精选模板库：主题菜单模板（封面用渐变 + emoji，无图片依赖）
  - 模板详情：介绍 + 菜品清单（名称/类型/分类/定价）
  - **一键导入**：模板内菜品写入"我的菜单"，同名同类型自动去重，缺失分类自动创建
- 灵感点滴：心意服务创意清单（静态灵感内容）
- 投稿：把自己的菜单整理投稿为模板（进入待审核队列，本期不做公开社区）

### 6.4 订单
- 双 Tab：我点的 / 点我的，下拉刷新 + 触底加载更多
- 状态机：`待接单 → 已接单 → 已完成`，分支 `已取消`、`申请取消`
  - 待接单：食客可免费取消（心意值即时退还）；主厨可接单或拒绝（拒绝=取消+退款）
  - 已接单：食客可发起取消申请 → 主厨同意（取消+退款）或拒绝（恢复）；主厨可直接取消（取消+退款）或完成
  - 已完成：食客可评价（星级 + 想说的话），仅一次
- 下单确认页：菜品信息、期望日期、留言、心意值余额与本次扣减
- 订阅消息（预留）：下单通知主厨、接单/完成/取消通知食客

### 6.5 我的
- 用户卡：头像（微信头像选择）、昵称（微信昵称填写）、个性签名
- 情侣卡：伴侣信息 + 在一起天数；未绑定则显示"去绑定"；已绑定可跳转解绑
- 心意值卡：余额 + 签到 / 明细入口
- 功能列表：我的菜单、我的订单、心意值、设置、组件预览、关于
- 分享：把小程序分享卡片发给伴侣（引导绑定）

## 7. 非功能要求（体验精良）

- 所有列表：骨架屏加载 + 空状态插画（emoji 体系）+ 失败重试
- 所有写操作：loading 锁 + 统一错误 toast + 后端校验
- 关键确认（解绑/取消订单/删除菜品）：ui-dialog 二次确认
- 主题：暖粉 / 雾蓝双主题，CSS 变量实现，设置页实时切换
- 性能：分包不做（体量小），lazyCodeLoading 按需注入，图片云存储压缩上传
- 交互细节：触感反馈（下单/签到成功 vibrate）、下拉刷新、安全区适配

## 8. 上线策略

- 注册个人主体小程序（免费），开通云开发**免费环境**（每月 40,000 资源点，免费 6 个月；2 人用量不足额度 2%）；
- 开发者工具上传代码 → 设为**体验版** → 伴侣添加为体验成员 → 扫码长期使用，无需提审发布；
- 到期后可选基础套餐（19.9 元/月）或按量付费（两人用量 < 1 元/月），数据可随时导出。

## 9. 迭代路线（本期不做）

- 微信支付接入（需企业主体）
- 情侣社区广场（公开 UGC，需内容安全审核）
- 定期回顾报告（每周被点/完成统计）
- 桌面小组件 / 订阅消息深度打磨
